# 使用说明

## 一、第一次打开

双击 `_scaffold\1 运行主程序.bat`（或命令行 `python PAC_Studio.py`）。

首次启动会自动建一个「默认方案」：

- 没命中任何规则时：**走代理**
- 默认代理地址：*****已脱敏***-内网IP:20808**
- 协议：**SOCKS5**

这个默认值就是 ZeroOmega 里 `+Master` 用的那个出口，可在「设置」里改。

## 二、添加规则

1. 点「+ 添加规则」
2. 选「怎么认网站」：
   - **域名后缀**（最常用）：填 `baidu.com`，`www.baidu.com`、`mail.baidu.com` 都算命中
   - **通配域名**：`*.google.com`、`cdn*.example.com`
   - **关键词**：网址或域名里包含这段文字就算
   - **URL 正则 / 主机名正则**：需要懂一点正则
   - **IP 段**：`***已脱敏***-内网IP/16`
   - **全部流量**：无条件命中，放最后才安全
3. 选「命中后怎么走」：直连 / HTTP 代理 / SOCKS5 / 混合（先 HTTP 再 SOCKS5）
4. 「单独指定代理地址」留空 = 用上面的默认代理地址
5. 确定

规则**从上往下**判断，先命中先生效。可以多选后「批量改动作 / 批量改代理 / 启用 / 停用」，也可以用「上移 / 下移」调顺序。

## 三、让 Windows 走 PAC

点工具栏「**应用到 Windows**」。

程序会：

1. 把你的规则编译成 `data\pac_current.pac`
2. **第一次**应用时备份你原来的系统代理（含原有的 AutoConfigURL）
3. 把 `AutoConfigURL` 指向这个文件，并把 `ProxyEnable` 置 0
4. 刷新系统代理设置（`InternetSetOption`）

生效范围：走 Windows 系统代理设置的程序（Chrome / Edge / IE / 大部分桌面程序）。Firefox 默认用自己的代理设置，需要在 Firefox 里选「使用系统代理设置」。

**没生效怎么办**：

- 重启浏览器，或等几秒
- 打开「PAC 脚本」页点「编译预览」，确认脚本内容没问题
- 某些老程序不认 SOCKS5 → 到「设置」把默认协议改成 **HTTP 代理**
- 点「还原原设置」可以随时回到你原来的系统代理

## 四、还原原来的系统代理

点「**还原原设置**」。

- 有备份：4 个键（`ProxyEnable` / `ProxyServer` / `ProxyOverride` / `AutoConfigURL`）一起还原
- 没备份过的：会先问你，确认后直接关闭系统代理（清空 AutoConfigURL）

默认「退出程序时自动还原」。如果你希望 PAC 长期生效（比如配合开机自启），到「设置」里取消勾选「退出程序时，还原我原来的系统代理设置」。

## 五、导入 ZeroOmega 配置

1. 在 ZeroOmega 里导出 PAC（选项 → 导出 PAC）
2. 本程序点「**导入 ZeroOmega**」，选那个 `.pac` 文件
3. 看报告：多少个 profile、展开多少条规则、有多少条无法转换
4. 选落地方式：
   - **新建方案**（推荐）：原方案一点不动
   - **替换当前方案**：覆盖当前方案全部规则
   - **追加到当前方案末尾**
5. 确定

实测 `OmegaProfile.pac`：5 个 profile → 4557 条规则，其中 2 条「`scheme === "http" && …`」组合无法安全转换，会在报告里列出来。

## 六、导出给 ZeroOmega

点「**导出 ZeroOmega**」，选保存位置。

生成的脚本与 ZeroOmega 原生导出结构一致，直接复制全文粘贴到 ZeroOmega 的「自动切换模式 → PAC 脚本」即可。

- `compatible` 风格：规则指向 `+Master`，多个不同出口会自动拆成 `+Master_2`…
- `flat` 风格：每条规则直接返回代理串，结构最简单

## 七、多方案

左上角「方案」下拉可以切换。「新建 / 改名 / 复制 / 删除」都在旁边。

典型用法：一个「公司（走公司代理）」、一个「家里（走 ***已脱敏***-内网IP）」，切换后点一下「应用到 Windows」。

## 八、开机自动应用

「设置」里勾选「开机后自动应用当前方案的 PAC」。

它写的是 `HKCU\Software\Microsoft\Windows\CurrentVersion\Run`，开机执行：

```
pythonw.exe "…\PAC_Studio.py" --apply-pac --silent
```

不需要管理员权限，也不会弹窗。想彻底关掉就取消勾选（会删掉那条注册表值）。

## 九、托盘

默认关闭窗口 = 最小化到托盘，不退出程序。

托盘右键菜单：显示主窗口 / 应用到 Windows / 还原原来的系统代理 / 退出。

「退出」才是真正退出（并按设置决定是否还原系统代理）。

## 十、文件都在哪

| 内容 | 路径 |
| --- | --- |
| 编译出来的 PAC（Windows 指向它） | `data\pac_current.pac` |
| 方案规则 | `data\profiles\<方案>.json` |
| 方案清单 / 当前方案 | `data\profiles.json` |
| 设置 | `data\pac_settings.json` |
| 系统代理备份（若备份过） | `data\system_proxy_backup.json` |
| 日志 | `logs\pac_studio.log` |
| 版本备份 | `version\<日期>-v<序号>\` |

整个目录可以直接复制到别的机器（便携）。
